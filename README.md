# Kids Lab con Eli

Aplicación web educativa para niños de primer ciclo: tecnología y matemáticas jugando, con Eli.

## Cómo probarla
Abre `index.html` en el navegador (doble clic). No necesita instalar nada.

## Estructura
- `index.html`: pantallas (bienvenida, perfil, mapa de niveles)
- `css/styles.css`: colores y animaciones
- `js/app.js`: lógica, sonidos, voz y ayudante Bit
- `img/`: personajes, logo y fondo
- `audio/`: voces y sonidos grabados (más adelante)
