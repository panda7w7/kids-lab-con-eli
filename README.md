# Kids Lab con Eli

Aplicación web educativa para niños de primer ciclo: tecnología y matemáticas jugando, con Eli, Robin, Mila, Luno y el robot Bit.

## Cómo probarla
Abre `index.html` en el navegador (doble clic). No necesita instalar nada.

## Estructura
- `index.html`: pantallas (bienvenida, perfil, mapa de niveles)
- `css/styles.css`: colores y animaciones
- `js/app.js`: lógica, sonidos, voz y ayudante Bit
- `img/`: personajes, logo y fondo
- `audio/`: voces y sonidos grabados (más adelante)

## Plan
- Nivel 1: Partes del computador · ¿Qué es una red? · Mensaje de Robin a Eli
- Nivel 2: por definir
- Números binarios: nivel avanzado
